Which one?

Scoring on dimensions that matter for §5 in this layout: how fast you read the run state, how clearly the three statuses separate, vertical cost (since §5 sits under two tall sections), and how well it scales if agent count grows past 8.

Recommendation: B · Vertical Timeline, with D as the "compact" toggle.
B nails the brief — "feel like a timeline / checklist, not a table" — and the connecting rail makes a live session feel alive (the next pending node is visually the "head" of the run). It loses on vertical cost, which is exactly the gap D fills: keep D as a density toggle (Tweaks → Compact) so users with crowded boards can collapse §5 without losing state legibility. Skip A (too settings-page) and C (stepper crowds past 8 agents, which is your stated count today).
