# Fin — Phase 4 debate r1 (plugin recommend 비용·ROI)

## §0 결론 먼저
- **신규 방식 = 운영비↑, 비재무 ROI↑↑.** 기존 BLOCK 대비 토큰 비용 늘지만 plugin store sunk cost 회수 직격.
- **단, "자동 1순위 적용"은 비용·신뢰 양면 위험.** 추천 → Master 선택 게이트가 ROI 우위.
- **추천 빈도 = 키워드 매칭 시만** (비용·노이즈 균형점). 매 prompt 추천은 토큰 누적 + 추천 피로 → 신뢰 추락.

## §1 비용 방향성

| 항목 | 종류 | 방향 | 비고 |
|---|---|---|---|
| 매칭 매 prompt | 운영비 | ↑ | 인덱스 in-context면 매번 재주입. 캐싱 시 ↓ |
| 추천 메시지 출력 | 운영비 | ↑ | 1~3줄이면 미미. 5+ 누적 |
| skill 자동 prepend | 운영비 | ↑↑ | skill 1건 = 수천 토큰. 여러 개 적용 시 폭증 |
| 인덱스 캐싱 | 일회성 | 1회 | 회수 빠름 |
| 추천 무시 매몰비용 | 비재무 | ↓ | Master 피로 누적 시 신뢰 추락 |

**숨은 비용**: 자동 적용 → 컨텍스트 오염 → 다음 turn 재호출 시 cache miss 누적 (이게 가장 큼)

## §2 BLOCK vs RECOMMEND

| 축 | BLOCK | RECOMMEND |
|---|---|---|
| 인지율 | ✗ Master 모름 | ✓ 직격 |
| FP 비용 | 차단 마찰 ↑ | 추천 무시 (마찰 ↓) |
| skill 활용률 | 미상 | ↑ |
| 토큰 비용 | 낮음 | 중~높음 |
| 시스템 신뢰 | 차단 짜증 | 추천 정확도 의존 |

**Master 의도 직격 = 신규 추천**. BLOCK은 인지 문제 미해결.

## §3 비재무 자산
- **회수**: 150+ skill = sunk cost. 미사용 = 자산가치 0. 추천 = 자산 활성화 = ROI 양 전환
- **함정**: 추천 정확도 <70% → "또 엉뚱한 추천" 학습 → 시스템 무력화 (BLOCK FP와 동형 위험)

## §4 결정 권고

| 결정점 | 권고 | 근거 |
|---|---|---|
| 자동 적용 vs 선택 게이트 | **선택 게이트** | 자동 = 컨텍스트 폭증 + 무관 skill 오염. 1초 클릭이 토큰 수천 절약 |
| 추천 빈도 | **키워드 매칭 시만** | 매 prompt = 피로·토큰 누적. 명시 명령만 = 인지 미해결 |
| 1차 PoC 카테고리 | **engineering · data 우선** | 사용 빈도 추정 최고. 정확도 측정 ROI 최대 |
| 추천 개수 | **Top 1~3** | 5+ 시 선택·노이즈 비용 급증 |
