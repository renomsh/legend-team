# Ace — Phase 4 debate r1 (구조+흐름 통합)

## §1 구조 진단 (Porter)

| 축 | 기존 BLOCK | 신규 RECOMMEND |
|---|---|---|
| 구조적 본질 | 강제 운영체제 (gate) | 디스커버리 보조 (assistive) |
| 권력 위치 | hook이 통제 | Master/Claude가 추천 선택 |
| Trade-off | 인지 실패 ↓, 마찰 ↑↑ | 마찰 ↓, 정확도 의존 ↑↑ |
| 실패 모드 | 우회·무시·끄기 | 노이즈 무력화 |

**판정**: BLOCK은 "skill 미사용" 근본 못 푼다 — 강제해도 적합한 skill을 모르면 무용. **새 방식이 jobs-to-be-done 정확 부합**.

**단**: 강제력 0 = 정확도가 유일한 생존 변수. 정확도 미달 = 시스템 자체 소멸.

## §2 흐름 (Keynes)

```
[+ loop]  추천 정확 → 채택률↑ → 데이터↑ → 정확도↑
[- loop]  추천 노이즈 → Master 무시 학습 → 추천 회피 → 기존 회귀
```

**비대칭 핵심**: 음의 루프가 훨씬 빠르다. Master는 노이즈 3-5회면 "추천 무시" 습관 고착. 양의 루프는 누적 데이터 수십 세션 필요.

**불확실성**: ~150 skill 중 자주 쓸 게 몇 개인지 모름. 롱테일이면 추천 베이스라인 자체가 노이즈.

## §3 지속 가능성 — Conditional Yes

조건:
1. 추천 신뢰도 임계값(top-1 채택률 >40%) 미달 시 자동 silent (출력 생략)
2. 노이즈 추천 누적 N회 시 해당 skill 추천 풀에서 자동 강등

조건 미설정 = 3개월 내 무력화 확정.

## §4 단일 최적해 (debate 입장)

**절충 금지, 단일 안만**:

| 결정축 | 단일 최적해 | 근거 |
|---|---|---|
| 트리거 시점 | **매 프롬프트 (조용히 평가)** | 조건부=룰 폭발, 매번=정확도만 통과한 것만 표면화 |
| 출력 형식 | **prepend 1줄 (top-1만)** | 별도 메시지=인지부하, 표=과시. 1줄=무시 비용 0 |
| 자동 적용 강도 | **Master 명시 채택만 호출** | 권력 전환 정합. 자동 호출=BLOCK 회귀 |
| 1차 PoC | **1 plugin skill 단일** | 카테고리=정확도 측정 불가. 1개 skill 입력→채택 곡선 먼저 |

**핵심 한 줄**: "조용히 매번 평가, top-1만 1줄 노출, 채택은 Master 결정." 이 외 변형은 BLOCK 회귀 또는 노이즈 폭발.
